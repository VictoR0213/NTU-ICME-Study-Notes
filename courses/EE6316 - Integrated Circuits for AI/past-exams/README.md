# EE6316 - Official Past Examination Papers

[Back to course](../README.md) | [All courses](../../../README.md)

Find official examination papers through **[NTU Library - Past-year examination papers](https://entuedu.sharepoint.com/sites/lib-repository/exam-question-papers)**.

1. Sign in with your NTU account.
2. Search for **EE6316**.
3. Select the academic year and semester you need.

The service is available to currently enrolled NTU students and staff. Read the [Library access guidance](https://libfaq.ntu.edu.sg/faq/262041) for details.

This directory provides the official link only; examination-paper files are not stored in this repository.
