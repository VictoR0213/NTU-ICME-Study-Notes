# EE6309 - VLSI Systems

Part of [NTU EEE MSc ICME Study Resources](../../README.md).

## Course Overview

**EE6309 — VLSI Systems** explores how to design digital systems for reliability and performance. Topics include data encoding, error detection, and error correction using techniques such as Hamming codes and cyclic redundancy checks (CRC). The course also covers signal integrity (transmission-line reflections, termination matching, and crosstalk), timing analysis (setup and hold constraints, slack, and clock skew), clock-domain synchronization and metastability, memory management and caching, parallel processing, and pipelining.

The course focuses on how digital systems transmit, store, and process data. It connects quantitative analysis with circuit design to help systems operate correctly, reliably, and efficiently at high speeds.
