# Contributing

Corrections, alternative derivations, and personally prepared study resources are welcome.

## Organisation

Use `courses/<COURSE-CODE>/` and the existing resource categories. Add a course README and update the root course index when introducing a new course.

- Quiz or revision sheet: include the course code and topic or assessment number.
- Personal exam solution: identify the course, academic year, semester, and question number.
- Assignment write-up: include the course code and assignment identifier.
- Official past-paper references: add links or search instructions under `past-exams/`.

The repository hosts personal study resources. Keep original university examination papers, lecture slides, handouts and recordings out of the repository; link readers to the official source instead.

## Worked solutions

Identify the exact paper and question number. Show assumptions, intermediate steps, and units where relevant. Distinguish your own reasoning from quoted or adapted sources, and mark unresolved points clearly. Personal solutions must not be presented as official marking schemes.

## Contributions and sources

Use English for repository documentation and navigation. Contribute material you may share, retain relevant attribution, and remove personal identifiers. Original written contributions are accepted under the license described in [LICENSE.md](LICENSE.md); third-party content retains its own rights.

For a correction, open an issue with the file path, page or question number, and suggested change, or submit a focused pull request.
